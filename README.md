# 🎛️ Ручний регулятор кольору RGB (Hue Controller) на Arduino

**Ручний регулятор кольору** — це проєкт плавної зміни відтінку підсвічування за допомогою обертання ручки потенціометра.

Один потенціометр дозволяє плавно проходити через увесь спектр кольорів (від червоного до фіолетового та назад до червоного) завдяки програмуванню триканального змішування кольорів RGB-модуля **KY-016**.

---

## 🎨 Принцип роботи (Спектр)

При обертанні потенціометра значення напруги перетворюється у відповідний колірний спектр:

* 🔴 **0° (Початок):** Червоний
* 🟡 **~60°:** Жовтий
* 🟢 **~120°:** Зелений
* 🩵 **~180°:** Блакитний
* 🔵 **~240°:** Синій
* 🟣 **~300°:** Пурпурний / Фіолетовий
* 🔴 **360° (Кінець):** Повернення до червоного

---

## 🛠 Обладнання та компоненти

| Компонент | Кількість | Примітка |
| :--- | :---: | :--- |
| **Arduino** (Uno / Nano / Pro Mini) | 1 шт. | Основний мікроконтролер |
| **Модуль RGB LED KY-016** | 1 шт. | Аналоговий RGB-світлодіод |
| **Потенціометр** (10 кОм) | 1 шт. | Регулятор відтінку |
| **З'єднувальні дроти** | — | Типу «папа-мама» або «папа-папа» |

---

## 🔌 Схема підключення

### 1. RGB-модуль KY-016
* **`-` (GND)** $\rightarrow$ **GND** на Arduino
* **R (Red)** $\rightarrow$ Digital Pin **9** (PWM)
* **G (Green)** $\rightarrow$ Digital Pin **10** (PWM)
* **B (Blue)** $\rightarrow$ Digital Pin **11** (PWM)

### 2. Потенціометр (3 контакти)
* **Крайній лівий контакт** $\rightarrow$ **GND**
* **Центральний контакт (вивід)** $\rightarrow$ Analog Pin **A1**
* **Крайній правий контакт** $\rightarrow$ **5V**

> **Примітка:** Режим `INPUT_PULLUP` для потенціометра **не використовується**, щоб не спотворювати аналоговий сигнал.

⚙️ Поліпшення проєкту
Регулювання яскравості замість кольору:

Якщо потрібно змінювати лише яскравість одного кольору, достатньо використати просту функцію map(val, 0, 1023, 0, 255) і передавати значення на потрібний пін.

3 потенціометри (Палітра RGB):

Підключивши три потенціометри (на піни A0, A1, A2), можна окремо регулювати яскравість червоного, зеленого та синього каналів для змішування будь-яких довільних відтінків.

🚀 Початок роботи
Зберіть схему згідно з описом.

Завантажте скетч у вашу плату Arduino.

Відкрийте Serial Monitor (9600 baud) для перегляду поточних значень.

Плавно обертайте потенціометр і спостерігайте за зміною кольору світлодіода!
